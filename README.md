# Mono Quotes

A minimalist random quote generator with a monochrome aesthetic.

## Preview

> "Believe you can and you're halfway there." — Theodore Roosevelt

## Features

- Random quotes fetched from API (dummyjson.com)
- Copy quote to clipboard
- Share quote to Twitter
- Text-to-speech (listen to quotes)
- Quote counter
- Toast notification on copy
- Error handling when API is unavailable
- Responsive design

## Built With

- HTML
- CSS
- JavaScript (Vanilla)
- Font: IBM Plex Mono (Google Fonts)
- API: [DummyJSON Quotes](https://dummyjson.com/quotes)

## What I Learned

- `fetch()` and `async/await` for API calls
- `try/catch` for error handling
- `navigator.clipboard.writeText()` for copy functionality
- `navigator.share` and Twitter intent URL for sharing
- `SpeechSynthesisUtterance` for text-to-speech
- CSS transitions and hover effects
- Responsive design with `@media` queries
